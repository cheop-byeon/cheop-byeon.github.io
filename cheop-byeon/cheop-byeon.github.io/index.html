Publications

Six papers from my PhD thesis, Automated Extraction of Design-Decision Rationales in Internet Protocols (University of Oslo) — each one builds on the last, from first dataset to a full retrieval-and-generation system.

01
ICMLCN 2024

Tell Me Why: Language Models Help Explain the Rationale Behind Internet Protocol Design

Built the first dataset linking RFC/I-D design decisions to their rationale, and a baseline NLP method to connect them — the data and methodological foundation for the rest of the thesis.

 02
IEEE Access

Automated Insights Into GitHub Collaboration Dynamics

Extended the approach to technical documentation and code, introducing an information-retrieval method (SIGIR) to link GitHub pull requests and issues — released as the CodeConvo dataset with open models on Hugging Face.

 03
NLDB 2025

Instruction Tuning TextFlow Semi-Automatic RFCs Generation

Tested whether LLMs could draft and edit Internet-Draft text directly, introducing TextFlow — a dataset and instruction-tuned model for semi-automatic RFC editing.

 04
ANRW 2025

Empowering IETF Collaboration with NLP Search Innovations and LLM-Enhanced RFC Writing

Brought the retrieval and generation work from Papers II and III together into one system — TextFlow Search and Edit — presented as a milestone summary of the thesis to the IETF research community.

 05
LREC 2026

Linking Rationale to Decision on Internet Standards: A Retrieval-Based Approach Using Synthetic Data

Moved from structured GitHub data to the messier IETF email archive, using synthetic data to train retrieval models robust enough to handle large-scale, unstructured discussion threads.

 06
SemTech 2026

Beyond the Rules: Understanding the Design Logic of Internet Standards

Closed the loop with a full retrieval-augmented system that surfaces relevant email discussions and generates grounded, LLM-written explanations for why a design decision was made — validated with a dedicated evaluation protocol.
